# 剝繭啟動器

剝繭本體在本 plugin 目錄（`skills/bojian/` 的上兩層）。啟動步驟：

1. 若尚未安裝依賴：在 plugin 根目錄執行 `npm install`（只需一次）。
2. 以背景程序執行 `node src/server.js`（工作目錄＝plugin 根目錄）。
   - 可用環境變數：`BOJIAN_PORT`（預設 8787）、`BOJIAN_DATA_DIR`（預設 `<plugin>/data/`）。
3. 啟動成功後告訴使用者：「剝繭開好了 → http://127.0.0.1:8787」，一句話即可，不要贅述。
4. 使用者要求關閉時，停掉該背景程序並回報一句。

注意：
- 伺服器會自己處理範例播種、垃圾桶與記憶垃圾桶清理，不需要你做任何資料操作。
- 第一次打開會問三題「介紹你自己」（可跳過）；之後它默默記下使用者的習慣與偏好（`data/memory/`），設定頁看得到、可撤。這些都在網頁裡發生，不經過本對話。
- 流程執行中的 AI 呼叫由剝繭經 `claude -p` 自行發起，不經過本對話。
- 不要替使用者改動 `data/` 裡的任何檔案。
