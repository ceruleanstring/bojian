# 剝繭（bojian）

把你的日常工作變成「愈用愈聰明的流程」。

你把一件常做的事（例如「跟主管報告季度業績」）用講的交給它，AI 拆成步驟；之後每次用，
它照你的習慣一次比一次做得更像你要的——你改過的，它會來問「以後都這樣？」，你點頭才算。

## 它能做什麼

- **用講的建流程**：描述一件事，AI 拆成節點化流程；或口述你平常的做法，照建。
- **畫布直接拉**：雙擊加步驟、拖著擺、從節點拉線接下一步；拉第二條線問你「同時做還是看情況」，自動長出並行／分岔。
- **停點過目**：關鍵步驟做完停下來給你看，直接在原文上改，改過的版本才往下走。
- **步驟細調**：每步一個抽屜——角色情境、限制、範例、輸出規格、模型檔位（快而省／深而慢）、出錯自動重試、驗收重點；常用內容存成常用一鍵帶入。
- **產出存檔**：步驟結果可存成 md／txt／csv／html／json 直接下載；可掛參考檔讓 AI 照你的風格做、用範本填空鎖定格式。
- **分岔與平行**：流程可以依人話條件走不同路、幾步同時進行。
- **愈用愈像你**：連兩次同樣的修改、開跑前同樣的微調、事後丟回的一句戰果——都會變成「它提議、你點頭」的升級；版本履歷隨時退回。
- **出錯講人話**：連不上、資料不全、檔案改壞，都停下來用人話告訴你怎麼辦；跑到一半關機也接得回來。
- **匯出分享**：流程存成單一檔案傳給別人；匯入前 AI 先掃可疑指示、逐句標黃給你過目（掃不出不代表安全，最後一關永遠是你的眼睛）。

## 需要什麼

- [Claude Code](https://claude.com/claude-code)（已登入）——剝繭掛在你自己的 Claude 上跑，不用另外付 AI 的錢
- Node.js 20+

## 開始用

```bash
git clone https://github.com/ceruleanstring/bojian.git
cd bojian
npm install
node src/server.js
```

打開 http://127.0.0.1:8787，點「跑跑看範例」。

也可以當 Claude Code plugin 安裝（含 `/bojian` 啟動 skill），或用環境變數調整：
`BOJIAN_PORT`（預設 8787）、`BOJIAN_DATA_DIR`（資料目錄，預設 `./data`）。

## 你的資料

全部在你電腦的 `data/` 資料夾裡（人可讀的 YAML 檔案樹）。沒有伺服器、沒有帳號、
沒有任何使用追蹤；搬資料夾＝搬家。AI 呼叫走你本機的 Claude，額度用你自己的。
